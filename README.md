# Substrate-only

Substrate-only is an exploratory benchmark and visualization surface for the Cranium cognitive-substrate concepts. It contains stress, governance, receipt-verification, and acquisition-data-room views.

This repository is a presentation and benchmark surface, not an alternate authority issuer. Authority decisions remain owned by the canonical [cranium-kernel](https://github.com/worthwyl2022-cloud/cranium-kernel).

## Verification

```bash
npm ci
npm run lint
npm run build
npm audit --omit=dev --audit-level=high
```

Benchmark values generated by the UI must be labeled as local simulations or measured runs; they must not be represented as external production evidence without a reproducible receipt and execution record.
